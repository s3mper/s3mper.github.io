# SQL - UNION

SQL의 `UNION` 연산자는 두 개 이상의 `SELECT` 쿼리 결과를 수직(행 기준)으로 하나로 결합할 때 사용한다.

## 1. 기본 특징 및 동작 방식

- 행 단위 결합(Vertical): `JOIN`은 테이블을 가로(열)로 확장하지만, `UNION`은 세로(행)로 데이터를 쌓아 합친다.
- 중복 제거(`UNION`): 기본 `UNION`은 두 쿼리 결과에서 중복된 행을 자동으로 제거하고 고유한 값만 반환한다.
- 중복 포함(`UNION ALL`): 중복 제거 연산 X → 처리 속도가 더 빠르다.

## 2. `UNION` 사용 조건

1. 열의 개수가 같아야 한다.
2. 열의 순서가 일치해야 한다.
3. 각 열의 데이터 타입이 서로 호환 가능해야 한다.

## 3. 문법

```SQL
SELECT [COLUMN NAME(S)] FROM TABLE1
UNION
SELECT [COLUMN NAME(S)] FROM TABLE2
```

## 4. 예제

customers 테이블

| id  | name |
| --- | ---- |
| 1   | 김민수  |
| 2   | 이서연  |
| 3   | 박지훈  |

employees 테이블

| id  | name |
| --- | ---- |
| 1   | 김민수  |
| 2   | 최유진  |

---

`UNION` 구문

```SQL
SELECT name FROM customers
UNION
SELECT name FROM employees
ORDER BY name;
```

| --- | ---- |
| 1   | 김민수  |
| 2   | 박지훈  |

| 5   | 최유진  |

## 5. `UNION` VS `JOIN`

|구분|UNION|JOIN|
|---|---|---|
|**결합 방식**|**수직 결합** (행(Row)을 아래로 이어 붙임)|**수평 결합** (열(Column)을 옆으로 확장함)|
|**결과 행(Row) 수**|두 쿼리의 행이 합쳐져 **증가**함|조건에 따라 유지되거나 줄어듦/증가함|
|**결과 열(Column) 수**|열의 개수와 데이터 타입이 **일치**해야 함|테이블 구조가 달라도 공통 키(Key)로 연결 가능함|
|**중복 처리**|기본적으로 중복 행 **제거** (`UNION ALL` 사용 시 중복 포함)|중복 제거 기능 없음 (조건에 맞는 데이터 매칭)|
|**주요 목적**|성격이 비슷한 데이터셋을 **하나의 목록**으로 합칠 때|서로 다른 테이블의 **관련 정보**를 한 번에 조회할 때|
